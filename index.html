비어 있으면 후기·추천·제안·관리 기능이 꺼지고, 저장소의 data/ 파일만으로 사이트가 동작합니다. 여기서 넣은 주소는 이 브라우저에만 저장됩니다. 모든 방문자에게 켜려면 index.html의 GAS_DEFAULT_URL을 채우세요.

관리자 인증

비밀번호는 Apps Script에서 확인합니다. 이 페이지 소스에는 저장되지 않습니다.

로그인한 동안 수업 상세의 후기마다 삭제 버튼과, 수업을 숨기거나 도안 링크만 지우는 관리자 조치 칸이 보입니다.

승인하면 시트 「수업」 탭의 해당 칸이 바뀌고, 나머지 두 언어는 자동 번역되어 함께 바뀝니다. 사이트에는 다음 데이터 발행 때 반영됩니다.

후기는 서로 다른 기기 3곳에서 신고되면 처리 전까지 자동으로 숨겨집니다. 원작자 삭제 요청은 수업 상세의 「이 수업 숨기기」(바로 반영)를 누르거나, 시트에서 해당 수업의 status를 「숨김」으로 바꾸거나 optout.txt에 영상·채널 ID를 적은 뒤 데이터를 다시 발행하세요.

수업 상세에서 「이 수업 숨기기」「도안 링크만 지우기」를 누른 수업입니다. 사이트에는 바로 반영되고, 다음 데이터 발행 때 숨긴 수업은 데이터에서 빠지고 도안 링크도 지워집니다. 해제하면 다음 발행 때 되돌아옵니다.
